About SecureMail

SecureMail is an email security application dedicated to helping users detect and prevent phishing, deceptive communications, malicious links, and dangerous attachments.

By integrating with the official Gmail API via Google OAuth 2.0, SecureMail performs transparent security evaluations on incoming messages without exposing credentials or sharing personal data with third parties.
